# MLY Modding

Personal modding / hardware projects.

## Projects

  a one-off PCB that emulates a 30-pin iPod to the car's factory interface while
  bridging modern Bluetooth (A2DP/AVRCP) to a USB-C iPhone: streams audio, passes
  track metadata to the dash, and relays dash/steering-wheel transport controls.
  Status: concept / feasibility.
